# 人物校准版：五官v2＋尾巴v5

用户指出第一版五官与目标不符：独立生成的通用眼型、镜像高光和整对眼睛缩放改变了身份，眉嘴的位置与形状也不正确。第一版六部件拼接已停用，原文件仅作历史保留，不能继续作为可用定稿。

当前使用 production/v1/neutral-front.png 的原图副本作为底图，SHA-256已验证一致，原眼、原眉、鼻子、腮红和闭嘴均保持原样。眨眼只覆盖左右眼的两个小区域，说话只覆盖嘴部区域。中央刘海和其他五官不随差分替换。

三张表情差分由内置图像生成工具编辑同一张原画而来，没有使用通用孤立五官。闭眼差分显示时向左平移4px，嘴部差分向左平移1px，依据未改动鼻子、下巴、领口和脸颊的局部匹配。PNG未重采样或改写，网页用SVG视窗和显示变换进行局部组合，边缘约1–2px柔化。

打开本地HTTP预览可切换五官近景/全身、原画对照、自动眨眼、保持闭眼，以及闭嘴/半开嘴/开嘴三档口型。选择本地音频或播放三秒测试音可检查音量驱动口型，默认静音输出；停止时恢复原画闭嘴。音频没有上传或录音。

本版是同脸局部差分的外观验证小样，不是完成的拆层PSD、连续眼皮变形或Live2D模型，也没有安装到DSH。正式分层仍需原画部件补画与绑定。

当前布局见 layers.json；完整提示词、来源、文件哈希与显示对齐见 correction-v2-manifest.json。旧 generation-manifest.json 和 rejected-v1 为已弃用方案记录。

## 尾巴轮廓与配色修正

用户指出旧尾巴未做好：尾柄与末端连成大叶片，双瓣分叉不清。v3 已收细尾柄，明确两个鲸尾瓣及中央缺口，尾根仍藏在裙后。尾部仅在下半身区域局部显示，原画五官及其差分保持不变；显示范围与对齐以当前 layers.json 为准。

最新尾部配色源图为 `assets/tail-v5/tail-blue-reference.png`。用户新提供的 `references/user/tail-color-reference-v5.png`（相对素材库根目录）是尾巴配色的优先参考，高于此前抱锅奔跑图的暖光配色。当前方向为冷靛蓝主体与柔和蓝色亮面，保留双瓣及中央缺口；不再沿用 v4 的紫灰配色，也不恢复 v3 的亮青蓝腹带。新参考受夜景蓝光影响，不能把取样色直接当作中性光下的设计色。

v3 结构稿和 v4 配色稿仅作历史对照，不是当前配色基准。页面可切换五官近景、全身与尾巴近景，比较尾部修正。尾部目前仍是静态局部小样，尚未拆分关节或绑定物理摆动；配色检查通过不代表用户已终审，也不代表 Live2D 制作完成。

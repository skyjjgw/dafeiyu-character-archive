# 大肥鱼五官分层小样

这是第一批六张独立透明PNG：底图、睁眼、闭眼、眉毛、闭嘴和开嘴。美术由内置图像生成工具编辑；原图保持不变。网页使用SVG视窗和定位组合素材，不改写PNG像素。

通过素材库本地HTTP服务打开本目录，可自动眨眼、保持闭眼观察、手动控制嘴部、播放六秒开合预览。选择本地音频后点击播放器播放，网页通过Web Audio检测实际音量幅度，控制嘴部开合；停止或暂停时闭嘴。测试音是三秒合成音，不是人物声线。默认静音输出，仍可检查口型；取消静音后可听音频。

本地音频只由浏览器读取，没有上传逻辑、录音或外部API。页面需要HTTP环境读取layers.json，不能直接以file协议打开。

本轮没有完成全身分层：脸底、头发、服装、四肢和尾巴仍合在底图内。左右眼也尚未按眼白、虹膜和眼皮进一步拆分。当前切换两种眼部差分，不是Live2D网格变形。眉毛、眼睛和嘴的对齐为小样定位，还需在正式原画中精修。

尚未创建分层PSD或Cubism工程，不把这些PNG重命名成PSD，也没有安装或替换DSH插件。后续应继续做眼睛细分、遮挡补画、前后发束/身体/尾巴分离，统一到同一画布后再进行正式模型绑定。

完整提示词、输入参考、生成源路径和哈希见generation-manifest.json；布局参数见layers.json。prepare.py只检查透明通道、生成布局元数据和测试音，不编辑美术图片。

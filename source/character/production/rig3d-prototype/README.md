# 大肥鱼 3D 骨骼与二次元渲染精修小样

本地地址：http://127.0.0.1:4334/production/rig3d-prototype/

这一版使用真实三维网格、40 骨和身体蒙皮，验证待机、招呼、走动、转身及尾发次级运动。脸部使用曲面和连续眼皮、口腔几何；不以完整立绘充当模型。当前已有可编辑 Blender 工程，仍是程序化精修小样，人物相似度、侧背结构、拓扑、手部和服装变形需要继续制作与多角度验收。

## 当前范围

- Three.js 本地 WebGL；实际接入 three-vrm 3.5.5 的 MToon 材质与描边，尚未加载完整 VRM 资产。
- lil-gui 0.21.0 调节头身、脸部、材质与尾发幅度，预设支持本机保存和 JSON 导入导出。眼部参数重建时同步调整眼孔与眼皮。
- Rapier 0.21.0 提供重力、固定平地、运动学胶囊与角色平移约束；`locomotion.js` 另做定长两骨腿部 IK、支撑脚世界锚定、抬脚弧线和小圆路径。它不模拟全身动态平衡、复杂地形或旋转扫掠。
- `physics.js` 为六条发链和一条尾链共 23 骨提供固定步长 Verlet、阻尼、重力、长度/关节角约束与球/胶囊碰撞。碰撞作用于骨尖粒子，不覆盖每个网格三角形；不可行约束会报告残余。没有全布料或全身碰撞。
- 可检查正、侧、背与近景，调速度、暂停、骨骼显示和表情，或重新居中。GUI 重建会释放旧控制器并重新初始化。
- 嘴部预览是程序化动作，没有接入语音、麦克风或音素识别。
- 浏览器 GLB 按钮保存当前模型、骨骼与姿势并转换基础材质；它与下面含形态键、动作的离线工程导出不是同一个交付入口。
- 本页独立运行，尚未装入 DSH 人物舞台；本轮未改模型密钥或 DSH 配置。大肥鱼仍定位为交流、创作、编程等能力持续扩展的全能虚拟人物。

## 已保存的原生工程

项目内已安装 portable Blender 4.5.15 LTS 和 VRM Addon 4.10.2，配置与扩展保存在项目工具目录。`../character3d/dafeiyu-master-v1.blend` 与 `../character3d/assets/dafeiyu-body-rig-v1.glb` 保存真实蒙皮、顶点色、`blink/aa/happy/sad` 四种形态及 `idle/wave/walk/turn` 四段烘焙动作。Blender 中尾发运动是可编辑关键帧，不是原生物理求解；`walk` 片段仍为原地步行，不包含 Web 的 Rapier 位移和脚 IK。

工程打包选定正面、v5 尾色与推定三视图。侧背补图是 AI 推定结构，不是原作者真值，也不证明各角度已经还原。实际模型四视图在 `../character3d/renders/`；原生编辑与重建说明见 `../character3d/NATIVE-README.md`。几何继续修改后，应按报告记录的源文件哈希重新导出、重建并核验。

## 正式制作流程

1. 以原 canonical 五官、最新 v5 尾巴配色及用户选定的视频形象统一正面、侧面、背面；当前程序化脸不自动替代原人物标准。
2. 在已有 `.blend` 中精修脸部轮廓、成组发束、鲸鳍耳、女仆服与鲸尾；补全侧背和遮挡区域。
3. 调整拓扑、UV、贴图、卡通阴影与描边；在多个视角核对是否仍为同一人物。
4. 继续修正身体、手与脸部权重和形态键，改善发束、裙摆、尾巴穿插、脚底接触和道具交互；现有简化物理不能替代这些制作。
5. 制作连续动作，调校重心、预备动作、缓动与过渡；分别验收待机、倾听、说话、招呼、移动。
6. 将 DSH 的行为事件交给独立角色动画控制器，语音音素驱动口型，处理打断和动作切换。DSH 不直接生成每一帧三维画面。

## 文件与依赖

- `character.js`：程序化角色、骨骼蒙皮和动作控制。
- `face.js`、`hair.js`、`costume.js`：脸部、发束与服装曲面。
- `app.js`：本地舞台、异步地面控制初始化与实例释放。
- `locomotion.js`、`physics.js`：地面/脚 IK 与尾发次级运动。
- `vendor/sources.json`、`refinement-sources.json`、`rapier-sources.json`：固定依赖、来源与校验记录；许可随库保留。
- `开源工具与精修工作流.md`：工具实际用途、许可与后续 VRM 流程。

本地运行不需要模型密钥，不调用付费生成接口。当前自定义骨架与 GLB 尚未声明符合 VRM，也未通过人物外观终审。

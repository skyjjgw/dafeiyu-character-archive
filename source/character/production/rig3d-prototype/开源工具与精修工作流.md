# 开源工具与精修工作流

状态日期：2026-10-26。当前已打通程序化模型、Web 调试与原生 Blender 工程；精修仍需逐项处理网格、拓扑、UV、权重和形态，滑块不能自动完成建模。

## 工具与实际接入

|---|---|---|
| [pixiv/three-vrm](https://github.com/pixiv/three-vrm/tree/v3.5.5) | v3.5.5，MIT | **已集成** MToon 材质与描边；尚未接入完整 VRM 资产、标准表情管理或弹簧骨。 |

| [dimforge/rapier](https://github.com/dimforge/rapier) | JS compat 0.21.0，Apache-2.0 | **已集成** WASM 运动学胶囊、重力与平地接触；脚部两骨 IK 由本项目实现。 |

依赖、校验与许可分别记录在 `vendor/` 的来源清单及 `../../tools/toolchain-manifest.json`。VRM 插件采用双许可，不能笼统把整套工具链标成 MIT。角色美术和外部模型仍需按自身来源核对。

面板可调头身、眼宽/高/距、虹膜、阴影、描边、颜色及尾发幅度，支持 localStorage 与 JSON 预设；眼部重建同步调整眼孔和眼皮。运行顺序为身体动画→Rapier 平移/双足 IK→尾发物理。后者是七链 23 骨的固定步长 Verlet 与球/胶囊骨尖碰撞，不是全布料、全身网格碰撞或动态平衡。

## 正式制作与运行

1. **核对身份**：以冬冰四个视频、选定 canonical 五官与 v5 尾色为准。`../character3d/references/turnaround-inferred-v1.png` 是补充推定视图，侧背不是原作者真值；用比例基准与多角度渲染继续核对。
2. **精修原生工程**：已有 `../character3d/dafeiyu-master-v1.blend` 和含蒙皮、顶点色的 GLB，可继续编辑。程序化三角网格仍可能需要重拓扑、UV、贴图与遮挡面补全；Eevee 使用原生卡通节点，Web MToon 不等于已移植完整着色器。
3. **修正绑定与动作**：工程已有 `blink/aa/happy/sad` 四种形态和 `idle/wave/walk/turn` 四段烘焙片段。尾发是烘焙关键帧，`walk` 仍为原地动作，未包含 Web 地面控制器。继续修权重、手势、接触与自然过渡。
4. **配置并验证 VRM**：再用已安装插件建立人形映射、表情、视线、材质与弹簧骨，执行标准检查。当前 `.blend`/GLB 尚非已完成 VRM。
5. **接回运行**：保留模型版本、参数、源文件哈希及重开核验记录；几何更新后重建导出。待人物与动作验收，再接 DSH 行为和语音。当前仍是独立预览，未改 DSH 运行环境或密钥。

这套工程服务于能力持续扩展的全能虚拟人物；目前的可编辑与可运行状态不代表外观终审、完整物理或生产模型交付。

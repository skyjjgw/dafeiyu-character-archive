# 原人物头饰的局部结构候选

本目录不改默认场景、静态 GLB、4348 原网页或冻结源。2026-10-28 Root 已做实际 WebGL
前/侧图审；**本版视觉失败，`visualPass=false`，仅留研究，不接默认人物。**不能因
拓扑数字通过而晋升为人物成品。

运行 `node prepare-review.mjs`（校验冻结源 SHA 后仅适配 Three import 路径）和
`node check.mjs`。独立对照页面：

`http://127.0.0.1:4334/production/appearance-preserving-runtime/hair-candidate/review.html`

同冻结人物、原图、正交镜头、sRGB / NoToneMapping、原三灯。可切原版/候选、强度、
±25/45/90° 和背面；按钮测量实际同机位正面 WebGL 像素差，并提供真实当前 PNG 导出。
这些绕拍是相机检查，不是 90° 颈部动作。

本轮局部改动：

- 原左右白色褶边六个 mesh 的 X/Y、UV 与原画不变，前/侧/背使用相同的 XY→Z 增量。
  原 z≈.05 的平面深度沿头壳外形温和展开；默认强度 .55，最大 Z 变化约 .1914 原单位。
  这是推定深度，不是作者真实三维几何或经测量的物理尺寸。
- 原真实头带 arch 的两端补各一面扇盖，共 2 个顶点、32 个三角形。原 1649 个位置和
  顶点色不改。canonical 边界 32→0，非流形、边方向冲突和退化三角均 0。
- 没有替换头发形状、眼型、脸型、身体比例或使用通用新人物。没有给 rest 模型添加假
  正弦摆动，也没有宣称发丝、布料碰撞或 Jolt 次级运动已完成。

`reports/geometry-check.json` 是数据检查：七个受影响 mesh 之外引用保持，原有顶点
X/Y 最大变化 0，原 UV 字节相同。**不证明前视像素必然相同**：Z 会改变遮挡，法线也会
改变 side MeshToon 着色。必须实际对照是否保留原画的白褶边/刘海层次。局部合理结构
修正可改变一些原来错误的遮挡；像素零差只是最初 renderer transfer 的基准，不是永久
冻结错误结构的要求。但新增穿插或破坏人物身份时应重新拟合或拒绝候选，不能重画脸来掩盖。

Root 实际前视比较为 640×704：RGB RMSE 约 4.6517、最大差 185、2637 像素通道差>1、
alpha 轮廓差 0。新右侧源灰白 scallop 因 Z 展开更可见，整体少女身份仍保持；此变化本身
并非必然失败。真正失败见 `reports/cua-hair-candidate-left90-20261028.png`：两条平行
直白带、内部三角裂缝和灰孔，frill 与独立 arch 未形成连贯布带。原自适应三角的 T 接在
弯曲后显露裂缝；只拉 Z 没有缝合拓扑，不能作为完整空间结构方案。

下一版应先建立 conforming frill 三角网格和共享边界双面薄壳，再将 frill 的附着边沿
原 arch/scalp 以连续跨深度 cloth strip 连接，保留白灰源画和前部大体 XY。该步骤尚未
实现；不能把本版的 arch 两端封口误报为整套头饰连续闭合。长发的多片层仍另需重拓扑。

尚未修复的原问题包括：frill/hair 的自适应三角 T 接、长发层之间的关系、源后发推定 UV
拉伸、脸部/身体侧视、头饰整体动态材料。闭合 arch 是局部结构进展，绝非全人物达标。

# 空心分层裙结构候选 v2

这是用户选择的 4348 原 maid 服装的局部结构实验，原 v1 与它的失败图保留。没有改正式页面、身体骨架、全人物相机或原图。外观、侧视与物理均未最终通过。

## 倒 V 的根因与标定边界

原 body-full.js 令整圈 `hemX=572+195*sin(theta)`，再统一令 `hemY=bottomAtX(hemX,frontContour)`。源正面外角约 py941、中心约 py1021；这条正面弧线被复制到背半圈，得到侧缝高、前后两端低的三维鞍形，90°成为巨大倒 V。v1 只增加 Z，必然会放大这一问题。它同时仍有上下实体中心封盖，以及原画/纯色半圈的硬分界。

源弧线很可能含有原插画的俯视/透视投影，而不是真实世界的环向高度。以固定俯视角 φ 为例，`projectY=Y*cosφ-Z*sinφ`；若将来统一标定，可用 `Y=(sourceY+Z*sinφ)/cosφ` 保同一基准投影。**全身、骨架和相机必须一致处理**，不能只修裙子就冒称全人物物理成立，也不能按观察角度换图。本轮没有应用这条全身标定变换。侧高的手帕形裙本身不必然违反物理；目前判未通过是实际造型与衔接达不到目标，不是用户要求了绝对水平裙摆。

## v2 实际结构

- 原向前外表面的 XY/UV 保留，仍用原纹样、原 navy/cream 调色及原 22 骨权重。推定背侧允许向原正面投影范围内收、降低垂褶，逐渐过渡，不再原样复制正面弧线到后面。
- 去掉原腰/下摆中心圆盘。外裙由外表面、内表面和窄布边组成，实际中心腔、腰环口与下摆环口开放；厚度 `.0035` 是尚未标定的 study units，未换算成米或真实材料参数。
- 独立较小的内衬采用另一层同样有厚度的裙布，与外裙存在空间，底边有真实顶点形成的细褶。它不是覆盖侧视缺陷的相机卡片；旋转后仍是同一套空间网格。
- 原前画逐渐过渡到原有侧背 navy/cream 调色，避免 `cos(theta)=0` 处硬切成两半。没有凭空绘制作者没有提供的背部服装图。未解决的侧背绘画质量仍须明确保留。

每层 29×96 外侧点、对应内侧点，总 5,568 顶点 / 11,136 三角形；各自是薄布的闭合环体（Euler characteristic 0），而不是填实整件裙子的实心体。两层共用原 Skeleton22，无新身体骨。

# Technical research snapshot — promotion stopped

The user rejected the new native character appearance. The visual baseline is the earlier painted curved-surface character at `http://127.0.0.1:4348/character-preview.html`. Nothing in this directory is approved as a replacement appearance or as reference-video quality. New native art/shader promotion is stopped; files remain available for technical research, without deleting or rolling back the physics work. The original runtime and DSH were not changed.

This independent `runtime-next` still contains only the frozen legacy native v2 GLB (5,961,816 B), not art v3–v8. It has never automatically refreshed to those assets. Its source hashes remain in `reports/runtime-asset.json` and each new scene snapshot.

Implemented technical changes:

- Instrumented non-fixed, unpaused wall-clock profiling. Baseline idle/movement/wave FPS were 21.84/21.28/22.19, with only 170–178 actual physics ticks per second against a configured 240 (simulation real-time factor .71–.74).
- Evaluated signed-dihedral material forces at 60 Hz and retained measured force between evaluations, applying forces every 240 Hz Jolt collision tick. All free SoftBody points and actual collisions remain. Cached unchanged facial weights/finger rotations. The first comparable wall-clock run measured 60.16/47.97/58.80 FPS and physics real-time factors .999/.979/1.001. These numbers predate later contact/material changes and are not final interaction or end-to-end latency certification.
- Corrected posed-contact timing. In the original node callback, wave right-hand proxy error reached .685 m and a fingertip 1.03 m. Contact transforms now update inside the final PhysicalBone modifier signal, when solved skin bone poses are valid; the same-phase probe then measured zero. Actual grasp and the 17 existing numerical checks still ran successfully after this change.
- Added conservative outer-hull turn-query broadphase. It is only a filter; overlap still invokes all actual hollow-support shapes. It is not attached as a solid contact cone and does not seal a tail hole.
- Captured identical actual GPU wave passes with/without ink and front/back diagnostics. Overlarge 7 mm detail outlines explain much of the black clothing network. The frozen v2 right palm is back-facing. Full bone/skin/GPU-evaluated vertex evidence excludes an IK-induced mirror for that pose: palm weighted determinant >=.9999535, wrist relative-rest rotation 0, area ratio >=.99755, no evaluated area-sign flips. The source team separately confirmed an inside-out right-palm bridge. This source issue was not declared solved with a double-sided material.
- Introduced mesh-based small-detail outline policy, but the old v2 source palm remains an acknowledged art/topology failure. Added optional per-material `vertexAlbedoRule=replace`; no new face/hair appearance has been ported or accepted.
- Reviewed and copied the bounded stdio transport, active only with `--character-stdio`. Scene handling stays on the main thread; no DSH/key/network/management capability is exposed. Bridge labels remain “本地动作联调 · DSH 未连接”. The bridge agent ran a real visible-scene state/action/closing/EOF cycle and confirmed both test PIDs exited; pickup was correctly recorded as range-rejected, not a successful grasp. Capture shutdown is cooperative so the stdin worker can finish.
- Following that bridge test, startup was changed to delay transport creation until cloth/secondary readiness and a real draw. This final readiness change has not been re-tested visibly because promotion was stopped. No such untested step is being reported as a completed cold-start latency fix.

Evidence lives under `reports/profile-realtime-baseline.json`, `profile-realtime-optimized.json`, `contact-posed-before.json`, `contact-posed-after.json`, `materials-wave-*.png`, `pose-wave-legacy.json`, and the current physical smoke/stress records. The 60 Hz material-force long test recorded no collapsed triangles and a few transient inverted cells during the free turn; numerical alarms are not visual acceptance. A new full test is required after any future integration.

Not yet implemented: visible action-check queue, visible action rejection feedback, cancel-target smooth return, natural gaze/head/torso attention, heel-toe gait/weight transfer/arm counterphase, true force-closure hands, schema2 arbitrary-triangle runtime bindings, native material-force helper integration, and final actual input/render latency. These were planned but must not be presented as finished.

The independent cloth-binding exporter `../native-character/scripts/export_cloth_bind_v4.py` is retained as a technical tool. Its provisional new-body binding was generated against an explicitly recorded source hash, and the source subsequently changed; it is not a final assetset and must not be promoted. No new character asset is installed into DSH. No running preview is required to retain these code/data results.

Place the future complete native character here as `character.glb`.

The engine fixture does not use the previous painted character as production art.
The supplied character must include continuous three-dimensional head/body/hair,
skinning, a complete armature, closed-eye/mouth expression morphs and animation
clips. Collision proxies and physical-bone/joint profiles are separate runtime
assets and must be calibrated against that character.

Run `../Run-Lab.ps1 -Mode InspectAsset` to inventory imported bones, skinned
meshes, expression morphs and animation names. No character art has been accepted
by this capability fixture.
